# Jev benchmark output

**What is llm-log-triage?** Paste a log line → structured JSON (severity, category, likely cause, suggested action, evidence). Small LangChain app with a golden set and CI merge gates — see [README § What is llm-log-triage?](../../README.md#what-is-llm-log-triage).

Generated by `scripts/jev_benchmark/run_lab.py`. JSON run files are gitignored; `SUMMARY.md` may be copied here after a local run.

```bash
./scripts/run_jev_benchmark.sh
```

**Mobile-friendly tables (Jev Medium post):** [`lab-tables.html`](https://khwajamkhan.github.io/llm-log-triage/jev-benchmark-runs/lab-tables.html) — light by default, **auto dark** when the reader’s OS/browser prefers dark (`prefers-color-scheme`). Preview locally:

```bash
cd docs/jev-benchmark-runs && python3 -m http.server 8765
# http://localhost:8765/lab-tables.html
```
